# Meshy 3D

Meshy runs in the cloud on Andrew's account and spends credits. Brenebase asks for his OK before any Meshy job that spends.

## Steps
1. Decide the input: text (a short clear description) or a picture (a clean front view on a plain background works best; a render from the Images tab is fine).
2. Write the prompt for the house style: low-poly, chunky shapes, flat colours, hand-painted look, no tiny detail, game asset, single object, T-pose for characters. Say the size ("a 1 m wooden barrel").
3. Text to 3D runs as a preview then a refine; check the preview before paying for the refine.
4. Retexture an existing model with a style prompt rather than starting again when only the colours are wrong.
5. Rig only humanoid characters standing in a T-pose or A-pose.
6. Download the GLB and keep the task id. For Breneland, the model then goes through the game's own intake (scale, toon material, colliders, a code-built fallback, a credit line), the same as free-model-intake steps 7 to 11.

## Rules
- Never start a credit-spending task without Andrew's OK; say what it costs if known.
- No logos or characters from published games or films in prompts.
- Check triangles and file size against the target game's budget before calling it done.

## Report
Task ids, prompt, credits used if known, triangles, file size, where the GLB is, a picture of it, and what is rough.
